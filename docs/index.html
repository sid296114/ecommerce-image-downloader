安装步骤

无需打包，四步即可加载到 Chrome 使用。

  1. 1

    下载并解压插件

    下载插件压缩包，解压到本地文件夹（例如 imagegrab）。

  2. 2

    打开扩展管理页

    打开 Chrome，地址栏输入 chrome://extensions 并回车。

  3. 3

    开启开发者模式

    点击页面右上角的「开发者模式」开关。

  4. 4

    加载已解压的扩展

    点击「加载已解压的扩展程序」，选择刚才解压的文件夹。
